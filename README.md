# Page Media Downloader

Бесплатное для личного и другого некоммерческого использования локальное расширение для **Chrome** и **Brave**: находит фото, прямые видео и аудио, уже доступные открытой HTTP(S)-странице, и скачивает выбранные файлы через менеджер загрузок браузера.

## Возможности

- Сбор изображений из `img`, `srcset`, CSS-фонов, Open Graph/Twitter, JSON-LD и прямых ссылок
- Сбор прямых видео из `video`, `source`, Open Graph/Twitter, JSON-LD и прямых ссылок
- Сбор прямого аудио MP3, M4A, AAC, WAV, OGG, FLAC и OPUS, а также WebM/MP4-контейнеров, явно раскрытых через `audio` или `source`
- Улучшенный Instagram-адаптер: открытый пост/Reel может отдать прямой MP4, даже если плеер показывает временный `blob:` URL
- Результаты идут в понятном порядке: видео, аудио, фото; воспроизводимое аудио поднимается первым в своей группе и помечается **Сейчас играет**
- Автоматический поиск при открытии popup и одна основная кнопка **Скачать выбранное · N**
- Выбор отдельных файлов, безопасный дополнительный поиск и явно отделённый режим полного автоскролла
- Дедупликация по типу, домену, пути и значимым параметрам медиа; временные подписи и токены не создают дубликаты
- Вся обработка локальная: без аккаунта расширения, сервера, аналитики и отправки истории браузера
- Файлы сохраняются в `Downloads/media_<site>_<id>/`; для Instagram — `Downloads/instagram_<source>_<id>/`

## Установка и обновление

1. Открой `chrome://extensions` или `brave://extensions`
2. Включи **Режим разработчика** (Developer mode)
3. Нажми **Load unpacked** / **Загрузить распакованное** и укажи папку `instagram-photo-downloader`
4. После изменения исходников нажимай **Reload** на карточке расширения

## Релизный ZIP

Для Chrome Web Store используется только минимальный архив из разрешённого списка runtime-файлов:

```sh
./scripts/package-chrome.sh
```

Скрипт создаёт `dist/page-media-downloader-1.6.1-chrome.zip`, кладёт `manifest.json` и `LICENSE.md` в корень и печатает SHA-256. Остальные документы, тесты, приватные evidence-файлы и исходный SVG в архив не попадают.

## Как пользоваться

1. Открой обычную HTTP(S)-страницу
2. Нажми иконку расширения — поиск начнётся автоматически
3. Результаты появятся в порядке **Видео → Аудио → Фото**; у воспроизводимого трека будет метка **Сейчас играет**
4. Сними галочки с ненужных файлов и нажми **Скачать выбранное · N**
5. Если страница ещё не догрузила материалы, открой **Больше медиа со страницы** и нажми **Найти больше** — эта операция ничего не скачивает
6. Там же можно явно запустить полный автоскролл: он прокручивает страницу и сразу отправляет найденные файлы в Downloads без предварительного выбора

Для ролика из сетки Instagram сначала открой конкретный пост/Reel: профиль часто содержит только обложку.

## Честные ограничения

- Расширение не перехватывает сетевой трафик, не записывает вкладку и не реконструирует HLS/DASH-сегменты.
- `blob:` является скачиваемым только тогда, когда страница дополнительно раскрывает прямой незашифрованный URL; универсального обхода `blob:` нет.
- DRM, paywall, login bypass, YouTube, приватные API, shadow DOM и медиа внутри недоступных cross-origin iframe не поддерживаются.
- Lazy-loaded медиа не появятся, пока страница их не отрисует; догрузи страницу и повтори скан.
- URL без расширения получают best-effort расширение по известному типу элемента.
- Сохраняй только собственный контент или материал, на который у тебя есть разрешение.

## Разрешения

| Permission  | Зачем |
|-------------|-------|
| `activeTab` | временный доступ только к текущей вкладке после клика пользователя |
| `scripting` | инъекция collector в вызванную пользователем вкладку |
| `downloads` | сохранение выбранных файлов |
| `storage`   | локальный статус фоновой пакетной загрузки |

Постоянного `<all_urls>` или другого host permission нет; content script не работает на каждой странице в фоне.
