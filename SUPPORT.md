# Support — Page Media Downloader

Page Media Downloader is a small, free browser utility. It finds photos and direct video files already exposed by the current HTTP(S) page. It does not bypass access restrictions or guarantee support for every website.

## Before reporting a problem

1. Open the specific page that contains the media. For an Instagram grid item, open the post or Reel itself.
2. Start or reveal lazy-loaded media, then reopen the extension and use **Find more** if needed.
3. Confirm the page is a normal `http://` or `https://` page. Browser settings pages and extension pages are intentionally unsupported.
4. Remember that HLS/DASH streams, DRM, `blob:` URLs without a disclosed direct source, paywalls, login bypass, private APIs, YouTube, and inaccessible cross-origin frames are outside the supported scope.

## Report an issue

Use <https://github.com/KikuAI-Lab/page-media-downloader/issues> and include:

- browser name and version;
- extension version;
- whether the missing item is a photo or video;
- the visible status or error text;
- minimal reproduction steps on a public page, when possible.

Do not post private page URLs, signed media URLs, credentials, cookies, account details, or personal content. A redacted screenshot is safer than a private URL. There is no guaranteed response time.

This project does not provide help with copyright infringement, DRM circumvention, paywall or authentication bypass, or unauthorized access.

# Поддержка — Page Media Downloader

Page Media Downloader — небольшое бесплатное расширение. Оно находит фотографии и прямые видеофайлы, уже раскрытые текущей HTTP(S)-страницей. Оно не обходит ограничения доступа и не гарантирует работу на каждом сайте.

## Перед сообщением о проблеме

1. Открой конкретную страницу с медиа. Для элемента из сетки Instagram открой сам пост или Reel.
2. Запусти или раскрой отложенно загружаемое медиа, затем снова открой расширение и при необходимости нажми **Найти больше**.
3. Убедись, что открыта обычная страница `http://` или `https://`. Настройки браузера и страницы расширений намеренно не поддерживаются.
4. HLS/DASH-потоки, DRM, `blob:` без раскрытого прямого источника, paywall, обход авторизации, приватные API, YouTube и недоступные cross-origin iframe не входят в поддерживаемый scope.

## Сообщить о проблеме

Используй <https://github.com/KikuAI-Lab/page-media-downloader/issues> и укажи:

- браузер и его версию;
- версию расширения;
- пропущено фото или видео;
- видимый статус или текст ошибки;
- минимальные шаги воспроизведения на публичной странице, если это возможно.

Не публикуй приватные адреса страниц, подписанные URL медиа, учётные данные, cookies, сведения аккаунта или личный контент. Скриншот с удалёнными личными данными безопаснее приватной ссылки. Гарантированного срока ответа нет.

Проект не помогает с нарушением авторских прав, обходом DRM, paywall или авторизации и несанкционированным доступом.
